# 3DX - Cross-Platform 3D Applications

A collection of interactive 3D applications built with modern web technologies, designed for cross-platform deployment.

## Projects

### 🏎️ [CarX Physics Simulator](CarXSimulator/)

A high-performance physics engine for realistic car simulation with:
- Professional Pacejka tire model
- Real-time 3D visualization with Three.js
- Interactive terrain generation
- Cross-platform support (Web, Android, Desktop)

**Quick Start:**
```bash
cd CarXSimulator/preview
python -m http.server 8080
# Open: http://localhost:8080/final-demo.html
```

[Full Documentation →](CarXSimulator/README.md)

---

### 🎯 [Cannon Shooter](cannon-shooter/)

A physics-based cannon shooting game demonstrating projectile motion and collision detection.

**Quick Start:**
```bash
cd cannon-shooter
npm install
npm run dev
```

[Full Documentation →](cannon-shooter/README.md)

## Technology Stack

- **3D Rendering**: Three.js, WebGL
- **Physics**: Custom engines, Pacejka tire model
- **Build Tools**: Vite, CMake
- **Platforms**: Web, Android (APK), Desktop (C++)
