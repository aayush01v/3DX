# Cannon Shooter

A small 3D physics mini-game built with React, Vite, Three.js, and Rapier. Take aim with the cannon, knock down every glowing target, and track your performance with a polished HUD.

## Getting Started

```bash
npm install
npm run dev
```

Visit `http://localhost:5173` to play locally. Deploy with `npm run build` and serve the generated `dist` folder.

## Controls

- **Mouse drag** — aim left/right and tilt the barrel
- **Scroll** — fine-tune pitch
- **Space** — fire a projectile
- **R** — reset the arena

Your score, accuracy, and remaining targets are always visible in the HUD, along with quick chip reminders for each control.
